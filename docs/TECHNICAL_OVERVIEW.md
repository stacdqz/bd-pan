# STA-PAN 技术概览（脱敏）

本文面向希望了解 STA-PAN 架构的开发者。为避免扩大攻击面，本文档不包含服务器地址、内部端口、密钥、运维命令等部署细节；完整内部资料见仓库根目录 `TECHNICAL.md`。

## 1. 项目定位

STA-PAN 是一个面向校园文件访问场景的权限化文件平台：前端提供浏览/预览/下载/上传体验，服务端网关统一处理认证、权限、存储桥接、日志与风控，存储层基于 AList，数据层使用 PostgreSQL（经 PostgREST 访问）。

## 2. 技术栈

| 层 | 技术 |
|---|---|
| 前端框架 | Next.js 16（App Router）、React 19 |
| 样式 | Tailwind CSS |
| 存储桥接 | AList（网盘 REST API） |
| 数据库 | PostgreSQL + PostgREST |
| PDF 渲染 | pdfjs-dist、@panzoom/panzoom（自研阅读器） |
| ZIP 打包 | archiver（流式） |
| 测试 | Playwright |
| 部署 | CDN（静态资源）+ 自建服务器（Nginx 反代）+ 自动部署流程 |

## 4. 认证与权限

- 登录接口签发 JWT（HMAC 签名），有效期 8 小时；
- 三级角色：`admin`（全部权限与用户管理）、`manager`（部分管理能力）、`guest`（游客/受限账号）；
- 用户级权限位覆盖浏览、搜索、下载、上传、删除、重命名等操作；
- 文件级权限规则使用正则匹配路径/文件名，按规则列表判定；
- 管理后台仅 `admin` 可访问。

## 5. API 路由分组

| 分组 | 端点 | 用途 |
|---|---|---|
| 登录/认证 | `login`、`_auth` | 登录、游客会话、JWT 校验 |
| 文件 | `alist`、`alist-batch-list` | 目录浏览、批量文件清单 |
| 下载 | `alist-download`、`alist-zip-download` | 单文件下载、ZIP 流式打包 |
| 上传 | `alist-upload` | 文件上传 |
| 预览 | `alist-zip-preview` | 压缩包目录预览 |
| 用户/设置 | `users`、`global-settings`、`change-password` | 用户管理、全局设置、改密 |
| 权限 | `file-permissions` | 文件级权限规则 |
| 日志/统计 | `log-action`、`track`、`admin-stats`、`debug-logs` | 操作日志、访问记录、统计 |
| 风控 | `check-risk`、`deny-stats`、`log-deny-event` | 风险评分、封禁统计、拒绝事件 |
| 备份 | `mg-backup` | 管理数据备份 |

## 6. 下载链路

- 小文件：直接触发下载，服务端自动补齐网盘要求的 User-Agent 标识；
- 大文件：提供多条线路（服务端中转、边缘加速、复制直链、兜底代理）；
- 批量下载：通过流式 ZIP 打包，按目录规模使用不同降级策略；
- 直链依赖正确的请求标识，下载工具需自行配置。

## 7. PDF 预览

- 使用 PDF.js 在浏览器端渲染，自研阅读器提供双指缩放/拖拽（Panzoom）；
- 预览数据可经过带缓存的网关链路，减少重复跨网络传输；
- 阅读器与 worker 静态资源自托管。

## 8. 风控与日志

- 操作日志记录文件操作与设备信息；
- 访问记录用于 IP 统计与在线用户；
- 风险评分基于拒绝事件、访问特征与设备指纹，支持自动封禁；
- 风控数据在多站点场景下按来源隔离/共享策略管理。

## 9. 数据库

主要表（脱敏描述）：
