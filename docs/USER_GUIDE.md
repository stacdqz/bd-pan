# STA-PAN 用户指南

本文面向使用 STA-PAN 文件平台的访问者，说明登录、浏览、预览、下载、上传与常见问题的处理方式。

> 本平台支持游客访问；目录与操作权限由管理员按角色和路径规则控制。

## 1. 登录

- **游客登录**：点击页面中心的"以游客身份登录"即可进入浏览（游客权限由管理员决定，可能看不到子目录）；
- **账号登录**：拥有专属账号的用户填写用户名与密钥登录；
- **登录有效期**：Token 有效期为 8 小时，过期后需重新登录；
- **首次访问较慢**：服务冷启动与存储服务首次握手可能需要数秒，属正常现象，等待或刷新即可；
- **界面主题**：页面右下角的月亮/太阳图标可切换明暗主题。

## 2. 浏览与搜索

- 根目录默认对所有访问者放行；进入子目录时会检查当前账号的浏览权限；
- 目录树支持列表/图标两种视图，右键菜单提供常用操作；
- 搜索依赖存储服务（AList）的索引，单次最多返回 5000 条结果；
- 搜索无结果时，请确认当前账号有搜索权限，或联系管理员刷新存储索引。

## 3. 在线预览

支持以下格式：

- **图片**：jpg / jpeg / png / gif / webp / svg / bmp
- **视频**：mp4 / webm / ogg
- **文档**：pdf、doc/docx/xls/xlsx/ppt/pptx（Office 走在线渲染）
- **文本/代码**：txt / md / js / ts / py / json / html / css / yml 等（≤2MB）
- **压缩包**：支持列出部分压缩包的文件目录，不支持在线解压

注意事项：

- 超过 2MB 的文本文件不会被在线加载，请下载后查看；
- Office 预览需要文件可被在线渲染服务访问，失败时请下载本地打开；
- 预览失败但下载正常时，可尝试更换浏览器或关闭拦截跨域请求的插件。

## 4. 下载

网盘对部分大文件（≥20MB）有 User-Agent 校验，系统会在下载链路中自动处理。

### 小文件（< 20MB）

直接点击文件即可触发下载，无需额外配置。

### 大文件（≥ 20MB）

下载弹窗提供多种方式：

| 方式 | 适用场景 |
|---|---|
| 服务端中转线路 | 手机首选，由服务端补齐网盘要求的标识 |
| 边缘加速线路 | 主线路拥堵时的备选 |
| 复制直链 | 适合下载工具（需在下载工具中设置对应的 User-Agent） |
| 兜底代理 | 其他方式不可用时的备选 |

> 点击下载后请耐心等待 1–2 秒链路解析，不要频繁刷新，以免触发节点限流。

### 批量下载

文件夹可通过 ZIP 流式打包下载；部分目录会分多个批次完成。

## 5. 上传

- 上传功能仅对有 `upload` 权限的账号开放；
- 进入目标目录后点击顶部"上传"按钮并确认；
- 上传走服务端中转，超大文件可能受连接时长限制。

## 6. 常见问题

**Q：第一次登录很慢，甚至短暂报错？**
属于冷启动与存储服务握手导致的正常现象，等待数秒或刷新即可。

**Q：游客能看到根目录，但进入子目录提示无权限？**
这是权限设计：根目录放行，子目录需要 `view` 权限。请联系管理员检查账号权限。

**Q：手机浏览器下载大文件返回 403？**
手机浏览器无法自行修改请求标识，请选择弹窗中的服务端中转或边缘加速线路。

**Q：复制直链后下载工具也返回 403？**
直链仍依赖正确的 User-Agent。请在下载工具中为请求头添加对应的网盘标识后再试。

**Q：登录后过一会儿需要重新登录？**
Token 有效期 8 小时，过期后需要重新登录，这是正常的安全机制。

**Q：上传很慢或中途卡住？**
上传经过服务端中转，速度受线路与文件大小影响；超大文件建议联系管理员确认线路。

## 7. 常见错误提示

| 提示 | 含义与处理 |
|---|---|
| 您的 IP 环境异常，已被防火墙阻断访问 | IP 被安全策略封禁，切换网络或联系管理员 |
| 系统已关闭游客访问 | 游客模式已关闭，请使用正式账号 |
| 用户名或密码错误 | 核对输入，注意大小写与多余空格 |
| 请先登录 | 登录已过期，刷新后重新登录 |
| 无权浏览子目录 / 无权搜索 / 无权下载 | 当前账号缺少对应权限，联系管理员 |
| 下载失败 (403) | 直链过期或标识校验失败，刷新后重新点击下载 |
| 下载失败 (502/503) | 中转节点临时不可用，稍后重试或换线路 |

## 8. 联系管理员

遇到无法自行解决的问题（持续 5xx、页面空白、权限疑问），请记录报错信息或截图并联系平台管理员。
