# STA-PAN

> 面向校园文件访问场景的权限化文件平台：整合 AList 存储桥接、Web 前端、服务端网关、数据库、预览、日志与多线路传输能力。
>
> A campus-oriented file platform with access control, previews, logging, and multi-route delivery.

## Project Status

- 状态：`Active development` · 校园/内部服务（游客可进入）
- 在线站点：[https://pan.stacdqz.tech](https://pan.stacdqz.tech)（游客可进入；部分目录与操作需要账号权限）
- 说明：本仓库为公开文档与代码仓库；在线站点属于组织内部服务，未授权用户无法直接使用。

## 这是什么

校园内大量学习资料存放在网盘上，直接分享会遇到下载限制、权限缺失、预览不便等问题。STA-PAN 把 AList 的存储能力与自建 Web 前端、服务端网关、权限体系、在线预览、操作日志和多线路下载组合成一个可管理的文件平台：

- 用户通过 Web 界面浏览、搜索、预览和下载文件；
- 管理员通过角色与文件级规则控制谁能访问什么；
- 下载链路自动处理网盘对 User-Agent 的校验，并提供多条可选线路；
- 操作日志、访问统计与风险评分帮助管理员了解使用情况。

## 核心能力

- **文件浏览与搜索**：目录树结构、列表/图标视图切换、右键菜单、基于 AList 的搜索；
- **在线预览**：图片、视频、PDF、文本/代码（≤2MB）、Office 文档、部分压缩包目录；
- **PDF 阅读器**：基于 PDF.js 与手势缩放库的自研阅读器；
- **下载**：小文件直连下载，大文件提供多条线路（服务端中转、边缘加速、复制直链、兜底代理），自动处理网盘 UA 校验；
- **批量下载**：文件夹以 ZIP 流式打包（多级降级策略）；
- **上传**：单文件上传，权限受控；
- **权限体系**：三级角色（admin / manager / guest）与多项权限位，支持文件级正则规则；
- **用户管理**：账号创建、权限分配、密码修改；
- **日志与统计**：操作日志、IP 访问统计、在线用户、服务端日志查看；
- **风险控制**：IP 封禁、风险评分、拒绝事件追踪、设备指纹；
- **移动端适配**：暗色主题与响应式界面。

## 架构概览（脱敏）

```text
用户浏览器
  │
  ├── 静态资源与页面 → CDN 边缘节点
  └── API 请求 → 服务端网关（Nginx 反代 + Next.js API）
                      │
        ┌─────────────┼──────────────────┐
        │             │                  │
     AList 桥接     PostgreSQL/PostgREST    PDF 预览缓存
   （网盘存储）   （用户/权限/日志/风控）    （PDF.js 阅读器）
```

核心思路：把频繁访问的存储、数据库与预览链路迁移到更接近数据源的节点，减少跨网络访问开销；前端通过 CDN 分发，API 与数据链路走受控网关。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Next.js 16、React 19、Tailwind CSS |
| 存储桥接 | AList |
| 数据库 | PostgreSQL（经 PostgREST 访问） |
| PDF 渲染 | pdfjs-dist + @panzoom/panzoom |
| ZIP 打包 | archiver（流式） |
| 测试 | Playwright（E2E） |
| 部署 | CDN + 自建服务器（Nginx 反代）+ 自动部署流程 |

## 安全与访问控制

- 平台支持游客访问，也提供账号登录；目录浏览与文件操作权限由管理员按角色和路径规则控制；
- 公开仓库不包含真实凭据：`.env.local` 等环境文件不提交；
- 本 README 与公开文档中的架构信息已做必要脱敏（不包含服务器地址、内部端口、密钥与运维细节）；
- 文档层面的脱敏不代表代码已经通过完整安全审计；
- 当前代码仓库不提供默认演示账号，也不公开管理入口细节。

## 本地运行

```bash
npm install
npm run dev
```

运行前需要准备环境变量（仅列出变量名，值以实际部署环境为准）：

```text
ALIST_*（AList 服务地址与凭据）
SUPABASE_URL / SUPABASE_*（或本地 PostgREST 地址）
ADMIN_TOKEN_SECRET（JWT 签名密钥，务必使用强随机值）
```

详细变量清单见仓库内开发者文档；真实值只放在 `.env.local` 或部署平台环境变量中，不要提交到仓库。

## 当前限制

- 文本预览限制为 ≤2MB，超大文本请下载后查看；
- 压缩包仅支持列出目录（部分类型），不支持在线解压；
- Office 预览依赖在线渲染服务，文件需可被公网访问；
- 上传走服务端中转，超大文件可能受平台连接时长限制；
- 搜索依赖 AList 索引，结果上限为 5000 条。
